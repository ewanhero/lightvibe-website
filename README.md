# LightVibe website

Public project information, setup and support. No app source, credentials or installers are included.

Mac Bridge downloads intentionally remain unavailable until a distributable build is ready.

Built with the Sites starter and exported as static HTML for GitHub Pages at the owner's explicit request. No Sites hosting resource is created.

Development: `pnpm dev`. Build: `pnpm build`. Only the static output is published.

Do not add APNs keys, server addresses, pairing codes or private screenshots. Do not publish this website as a payment portal or commercial SaaS using GitHub Pages.
